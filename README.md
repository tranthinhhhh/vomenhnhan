# Vô Mệnh Nhân

Trang giới thiệu dự án tu tiên gốc của người Việt: truyện chữ, truyện tranh và hoạt hình, phát hành song song.

- Sửa link (YouTube, truyện chữ, truyện tranh, liên hệ, tiến độ) ở khối `CAI_DAT` cuối file `index.html`.
- Trang tĩnh một file, đăng bằng GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/root`).
